Good to know

Smart mode downscales large embedded JPEGs (max 1600px, q85) while keeping text selectable — best for photo-heavy PDFs. Rasterize renders every page to an image: smallest for scans, but text is no longer selectable. Lossless only repacks the file. Each uploaded PDF is converted with the settings above — one file downloads directly, multiple files are zipped. PDF version & PDF/A adjust header/metadata — verify PDF/A with veraPDF.
